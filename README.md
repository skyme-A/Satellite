# Aether — Deep Space Downlink

A minimalist space telemetry dashboard built with Python and Streamlit to view high-resolution imagery and scientific downlinks from NASA and deep-space missions.

---

## Features

- **Planetary Views:** Switch between Deep Cosmos, the Sun (Photosphere & EUV Corona), Mars (Jezero Delta), and Jupiter.
- **Optical Zoom:** Inspect surface details using 1x, 2x, and 3x crop modes.
- **Export Raw Frames:** Download uncompressed PNG images stamped with UTC timestamps.
- **Responsive Dark UI:** Designed with a clean, low-glare dark layout optimized for both desktop and mobile screens.

---

## Tech Stack

- **Python 3.10+**
- **Streamlit** (Web framework)
- **Pillow / PIL** (Image cropping & buffer processing)
- **Requests** (API data fetching)
