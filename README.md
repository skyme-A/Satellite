# Aether — Deep Space Downlink

A space telemetry dashboard built with Python and Streamlit to view high-resolution imagery and scientific downlinks from NASA and deep-space missions.

---

## Features

- **Planetary Downlinks:** Switch between Deep Cosmos, the Sun (Photosphere & EUV Corona), Mars (Jezero Delta), and Jupiter.
- **Optical Inspection:** In-memory 1×, 2×, and 3× crop zoom modes.
- **Frame Export:** Download uncompressed PNG frames with UTC timestamps.
- **Gemini Dark Theme:** Low-glare dark layout optimized for both desktop and mobile screens.

---

## Tech Stack

- **Python 3.10+**
- **Streamlit**
- **Pillow (PIL)**
- **Requests**
